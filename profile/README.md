## Recruit with your assistant

| Repository | What it provides |
| --- | --- |
| [agent](https://github.com/vitaedotai/agent) | Connect Claude, Codex, Cursor, Grok, and other compatible assistants to Vitae. Includes the platform operating skill and client connection packages. |
| [skills](https://github.com/vitaedotai/skills) | Recruiting playbooks for job intake, sourcing, candidate outreach, screening, interviews, and candidate presentation. |

The connector handles access to your Vitae workspace. The recruiting skills teach repeatable methods and can also work from information you supply.

## Get started

For recruiter skills, follow the installation instructions in [vitaedotai/skills](https://github.com/vitaedotai/skills). For connected work, follow [vitaedotai/agent](https://github.com/vitaedotai/agent) and complete Vitae sign-in.

You can also use the [hosted connector setup page](https://mcp.vitae.ai) or read the [MCP documentation](https://docs.vitae.ai/reference/mcp).
